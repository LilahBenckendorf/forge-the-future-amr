# Forge the Future

A public event website for an engineering evening at The Glade in Berkeley focused on advanced manufacturing, metallurgy, AI, robotics, mechanical engineering, and mechatronics.

**Event:** Thursday, September 10 at 6:00 PM  
**Location:** The Glade, Berkeley  
**Attendance:** No invitation required

Questions can be sent to both `lilahbenckendorf@berkeley.edu` and `tim@advancedmetalresearch.com`.

## Development

```bash
pnpm install
pnpm dev
```

Pushes to `main` are published automatically with GitHub Pages.
